# SAME 30

**One level. Everyone. Thirty seconds.**

SAME 30 is a lightweight, browser-based daily survival game. Every player gets the same deterministic challenge for the day: collect the light, avoid the noise, and survive for as long as possible.

It is designed to be instantly playable on mobile and desktop without accounts, databases, servers, or heavy dependencies.

## Features

- Daily seeded challenge shared by every player
- 30-second survival gameplay loop
- Mouse, touch, arrow-key, and WASD controls
- Progressive difficulty: Warm Up, Crowd, Reverse, and Panic
- Local personal best using `localStorage`
- Shareable result flow with native share and clipboard fallbacks
- Optional lightweight sound effects
- Responsive canvas rendering for desktop and mobile browsers
- No framework, backend, database, or build step required

## Run locally

Open `index.html` directly in a browser, or serve the folder with any static server:

```bash
npx http-server .
```

Then open the local URL shown in your terminal.
